  imprimiendo el ticket: un ticket continuo con los diferentes pasos, y por encima salen esos resaltes digitales».
  · LA IMPRESORA: una ranura oscura que se queda fija a tres cuartos de la pantalla (sticky) mientras pasa la sección; el ticket SALE DE ELLA con el
    scroll, a tirones de una línea (la cadencia de una térmica): lo que ya está por encima de la ranura está impreso; lo de debajo, aún no existe.
  · UN SOLO TICKET, largo, con los cinco pasos seguidos (01 tu marca → 02 el arnés → 03 tu equipo pide → 04 queda escrito → 05 la cuenta), canto
    dentado arriba y abajo. Es la receta REAL entregada a Neety (su library).
  · HUMANO: la TINTA A MANO en Coral se dibuja sobre cada paso cuando termina de imprimirse (círculo, subrayado, tachado, vistos).
  · DIGITAL: a la vez, a su lado (izquierda y derecha, alternando) aterriza la pieza de interfaz de ese paso, recta y nítida.
  Sin JS o con movimiento reducido: el ticket entero, marcado y con sus piezas.

<script>
  const sec = document.querySelector<HTMLElement>('[data-receta]');
  if (sec) {
    const reducido = matchMedia('(prefers-reduced-motion: reduce)').matches;
    const imp = sec.querySelector<HTMLElement>('[data-impresora]')!, ticket = sec.querySelector<HTMLElement>('[data-ticket]')!;
    const bloques = [...sec.querySelectorAll<HTMLElement>('[data-bloque]')];
    const LINEA = 19; // un tirón de la impresora = una línea del ticket (0,78 rem × 1,55)
    let vista = false, raf = 0;
    const pintar = () => {
      raf = 0;
      // lo impreso: desde el borde de arriba del ticket hasta la boca de la impresora (redondeado a líneas enteras)
      const boca = imp.getBoundingClientRect().bottom, tr = ticket.getBoundingClientRect();
      const hecho = Math.max(0, Math.min(tr.height, Math.floor((boca - tr.top) / LINEA) * LINEA));
      ticket.style.setProperty('--impreso', `${hecho}px`);
      ticket.classList.toggle('acabado', hecho >= tr.height - 1);
      // cada paso, cuando ya ha salido entero: su tinta y su pieza digital (y se quedan)
      bloques.forEach((b) => { const r = b.getBoundingClientRect(); if (r.bottom - 8 <= boca) b.classList.add('marcado'); });
    };
    const pedir = () => { if (vista && !raf) raf = requestAnimationFrame(pintar); };
    if (reducido) { sec.classList.add('sin-imprenta'); bloques.forEach((b) => b.classList.add('marcado')); }
    else {
      sec.classList.add('con-imprenta');
      new IntersectionObserver((e) => { vista = e[0].isIntersecting; pedir(); }, { rootMargin: '20% 0px' }).observe(sec);
      addEventListener('scroll', pedir, { passive: true });
      addEventListener('resize', pedir);
      pintar();
    }
    (window as any).__receta = () => ({ impreso: ticket.style.getPropertyValue('--impreso'), alto: ticket.offsetHeight, marcados: bloques.map((b) => b.classList.contains('marcado')) });
  }
</script>
